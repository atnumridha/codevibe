CodeVibe connects to AI models through a **provider**. You have three paths:

- **Codex auth** (default): reuse your local `~/.codex/auth.json` session.
- **CodeVibe account provider**: sign in with a supported hosted account flow when configured.
- **Bring Your Own Key (BYOK)**: use your own provider credentials (cloud or local runtimes).

## IDE Setup

<Steps>
  <Step title="Open CodeVibe Settings">
    Click the settings icon in the CodeVibe panel.
  </Step>

  <Step title="Select Provider">
    Choose your desired provider from the **API Provider** dropdown.
  </Step>

  <Step title="Authenticate">
    - **Codex auth:** keep `~/.codex/auth.json` populated; CodeVibe loads it by default.
    - **CodeVibe account provider:** click **Sign In** and complete OAuth.
    - **BYOK cloud provider:** Paste your API key into the **API Key** field.
    - **Local runtime (Ollama/LM Studio):** no key needed; ensure runtime is running.
  </Step>

  <Step title="Select Model">
    Choose your desired Codex, OpenAI, Claude, Gemini, or compatible model from the **Model** dropdown.
  </Step>
</Steps>

## Provider Options

### Codex Auth

- Reads `~/.codex/auth.json`, `~/.codex/installation_id`, and local Codex model cache when present
- Uses `openai-codex` as the default Plan and Act provider
- Preserves Codex session headers and refresh behavior without logging token contents

### CodeVibe Account Provider

- One sign-in when a hosted account backend is configured
- Unified model selection from the CodeVibe settings UI
- Legacy provider IDs may remain internally so existing profiles continue to load

Run models on your own hardware for complete privacy and zero per-request costs.

| Provider | Best For | Setup Guide |
|----------|----------|-------------|

Local models require sufficient hardware (especially GPU memory). See [Running Models Locally](/running-models-locally/overview) for requirements.

## CLI Setup

```bash
# Authenticate from the terminal
codevibe auth

# Shorthand
codevibe a
```

Runs the same auth flow as IDE setup.

## Troubleshooting

| Issue | Fix |
|-------|-----|
| "Unauthorized: Please sign in" | Session expired. Click **Sign In** to re-authenticate. |
| Browser doesn't open | Check default browser settings. Copy the URL from the CodeVibe output panel manually. |
| Frequent re-authentication | Check org security policies. Ensure you're not clearing IDE secrets. Try a full sign-out/sign-in. |
| Can't access organization | Ask your workspace admin about permissions. Sign out and back in. |
