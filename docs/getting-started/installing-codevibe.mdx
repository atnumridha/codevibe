- [IDE Extension](#ide-extension) — VS Code and compatible editors

## IDE Extension

Use this if you want Codie inside your editor UI.

<Tabs>
  <Tab title="VS Code and compatible editors">
    <Steps>
      <Step title="Open Extensions">
        Press `Ctrl/Cmd + Shift + X`.
      </Step>
      <Step title="Install Codie">
        Install the latest Codie VSIX from [GitHub Releases](https://github.com/atnumridha/codevibe/releases/latest), or install the local VSIX generated by `npm run package:github-vsix`.
      </Step>
      <Step title="Open Codie">
        Run `Codie: Open Codie` from Command Palette.
      </Step>
	      <Step title="Authorize Codie">
	        Complete provider setup in Codie settings. Codie can also import local auth files when compatibility support is enabled.

        [Authorize with Codie](/getting-started/authorization)
      </Step>
    </Steps>

    <Note>
    Windsurf and VSCodium use Open VSX. The install flow is the same.
    </Note>
  </Tab>

  <Tab title="JetBrains">
    <Steps>
      <Step title="Open Plugins Marketplace">
        **Settings** → **Plugins** → **Marketplace**.
      </Step>
      <Step title="Install Codie-compatible plugin">
        JetBrains support remains on the upstream-compatible plugin track while Codie focuses on VS Code, CLI, and standalone UI.
      </Step>
      <Step title="Open the agent panel">
        Open the installed agent panel from the IDE tool windows menu.
      </Step>
      <Step title="Authorize">
        Complete provider setup in the agent settings.

        [Authorize with Codie](/getting-started/authorization)
      </Step>
    </Steps>

    Alternative: install the upstream-compatible plugin from the JetBrains Marketplace.
  </Tab>
</Tabs>

## CLI

Use this if you want Codie in terminal workflows (interactive + automation).

<Steps>
  <Step title="Install Node.js">
    Install Node.js 20+ (22 recommended).
  </Step>
  <Step title="Install CLI">
    ```bash
    npm install -g codevibe
    ```
  </Step>
  <Step title="Authenticate">
    ```bash
    codevibe auth
    ```
  </Step>
  <Step title="Run Codie">
    ```bash
    codevibe
    # or
    codevibe "your task"
    ```
  </Step>
</Steps>

More details: [CLI Installation & Setup](/usage/cli-overview)

## Kanban

Use this if you want task-board workflows with agent execution.

<Steps>
  <Step title="Install Node.js">
    Install Node.js 18+.
  </Step>
  <Step title="Launch Kanban">
    ```bash
    codevibe kanban
    ```
  </Step>
</Steps>

More details: [Kanban](/usage/kanban)

## SDK

Use this if you are building your own app or agent on top of the Codie runtime.

<Steps>
  <Step title="Create project">
    ```bash
    mkdir my-agent && cd my-agent
    npm init -y
    ```
  </Step>
  <Step title="Install SDK">
    Follow the SDK examples for the currently published runtime package and import surface.
  </Step>
  <Step title="Build and run">
    Browse SDK examples to run your first agent.
  </Step>
</Steps>

Start here: [SDK Examples](/sdk/examples)
