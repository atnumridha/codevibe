## What is CodeVibe?

CodeVibe is an editor-native AI coding agent that lives in your editor, terminal, and standalone workflows. It can read and write files, run terminal commands, use a browser, and help you build features through natural conversation. Every action stays behind explicit approval and review gates unless you opt into autonomous execution.

### Agent Core (SDK)

The SDK is the agent core used by CodeVibe. Use it to build your own applications, automations, and integrations while CodeVibe keeps selected upstream package boundaries internally for clean patching.

## Other IDE Supports

CodeVibe works first as a VS Code extension and CLI, with compatibility paths for **Cursor**, **Windsurf**, **VSCodium**, **JetBrains**, **Zed**, and **Neovim** through extension-compatible and ACP workflows.
