CodeVibe CLI supports the [Agent Client Protocol (ACP)](https://agentclientprotocol.com/), an open standard that enables AI coding agents to work across different editors and IDEs. This means you can use the full CodeVibe agent—with all its capabilities including Skills, Hooks, and MCP integrations—in your preferred development environment.

## Why ACP?

- **Editor flexibility**: Use CodeVibe in JetBrains, Neovim, Zed, or any ACP-compatible editor
- **No feature compromises**: Full access to CodeVibe's capabilities regardless of editor
- **Team consistency**: Same AI assistant across different developer workflows
- **Open standard**: Built on Zed's open Agent Client Protocol specification

## JetBrains IDEs

[JetBrains](https://www.jetbrains.com) IDEs include IntelliJ IDEA, PyCharm, WebStorm, and more. They offer built-in AI Assistant with ACP support.

<Note>
**Recommended: Native JetBrains Plugin**

For the best JetBrains experience, install the [native CodeVibe plugin](/getting-started/installing-codevibe#jetbrains-ides) from the JetBrains Marketplace. It provides full IDE integration and the complete CodeVibe experience.

The ACP setup below is an alternative way to use CodeVibe CLI features in JetBrains IDEs.
</Note>

Alternatively, you can run CodeVibe CLI in IntelliJ IDEA, PyCharm, WebStorm, and all other JetBrains IDEs through their built-in AI Assistant with ACP support.

### Setup

1. **Install CodeVibe CLI** (if not already installed):
   ```bash
   npm i -g codevibe
   ```

2. **Authenticate with CodeVibe**:
   ```bash
   codevibe auth
   ```

3. **Configure JetBrains AI Assistant**:
   - Open your JetBrains IDE
   - Navigate to `Settings | Tools | AI Assistant | Agents`
   - Click "Add Custom Agent"
   - This opens/creates `~/.jetbrains/acp.json`

4. **Add CodeVibe to `acp.json`**:
   ```json
   {
     "agent_servers": {
       "CodeVibe": {
         "command": "codevibe",
         "args": ["--acp"],
         "env": {}
       }
     }
   }
   ```

5. **Use CodeVibe**:
   - Open the AI Chat tool window
   - Select "CodeVibe" from the agent dropdown
   - Start coding with CodeVibe in your JetBrains IDE!

<Tip>
JetBrains AI Assistant can expose its built-in MCP server to CodeVibe, giving CodeVibe access to IDE-specific tools and context.
</Tip>

## Neovim

[Neovim](https://neovim.io) is a hyperextensible Vim-based text editor loved by developers for its speed and flexibility. Use CodeVibe in Neovim through the [agentic.nvim](https://github.com/carlos-algms/agentic.nvim) or [avante.nvim](https://github.com/yetone/avante.nvim) plugins, which provide ACP integration.

### Setup with agentic.nvim

1. **Install CodeVibe CLI** (if not already installed):
   ```bash
   npm i -g codevibe
   ```

2. **Authenticate with CodeVibe**:
   ```bash
   codevibe auth
   ```

3. **Install agentic.nvim** using lazy.nvim:
   ```lua
   {
     "carlos-algms/agentic.nvim",
     opts = {
       provider = "codevibe-acp",
       acp_providers = {
         ["codevibe-acp"] = {
           command = "codevibe",
           args = {"--acp"},
         },
       },
     },
     keys = {
       {"<C-\\>", function() require("agentic").toggle() end, mode={"n","v","i"}, desc="Toggle CodeVibe Chat"},
     },
   }
   ```

4. **Use CodeVibe**:
   - Press `<C-\>` to toggle CodeVibe chat
   - Start coding with CodeVibe in Neovim!

### Setup with avante.nvim

Follow the [avante.nvim documentation](https://github.com/yetone/avante.nvim) for configuring external ACP agents and point it to `codevibe --acp`.

## Zed

[Zed](https://zed.dev) is a high-performance, multiplayer code editor built from the ground up for speed and collaboration. Zed's team created the Agent Client Protocol, making CodeVibe a natural fit for this editor.

### Setup

1. **Install CodeVibe CLI** (if not already installed):
   ```bash
   npm i -g codevibe
   ```

2. **Authenticate with CodeVibe**:
   ```bash
   codevibe auth
   ```

3. **Configure Zed**:
   - Open Zed settings (`Cmd/Ctrl + ,`)
   - Add CodeVibe to your `settings.json`:
   ```json
   {
     "agent_servers": {
       "CodeVibe": {
         "type": "custom",
         "command": "codevibe",
         "args": ["--acp"],
         "env": {}
       }
     }
   }
   ```

4. **Use CodeVibe**:
   - Open the AI assistant panel
   - Select "CodeVibe" from the agent dropdown
   - Start coding with CodeVibe in Zed!

## Other Editors

Any editor that supports the Agent Client Protocol can run CodeVibe. Check your editor's documentation for ACP configuration instructions, then point it to:

```bash
codevibe --acp
```

## Troubleshooting

### Agent not appearing

- Ensure CodeVibe CLI is installed globally: `npm i -g codevibe`
- Verify authentication: `codevibe auth`
- Check that `codevibe --acp` runs without errors
- Restart your editor after configuration changes

### Permission errors

If CodeVibe can't access files or run commands:
- Check that your editor's ACP integration passes the correct working directory
- Verify file permissions in your project
- Ensure CodeVibe has approval settings configured correctly

### Connection issues

- Make sure no other CodeVibe instance is using the same configuration directory
- Check editor logs for ACP-related errors
- Try running `codevibe --acp` manually to test the connection
