Codie CLI supports the [Agent Client Protocol (ACP)](https://agentclientprotocol.com/), an open standard that enables AI coding agents to work across different editors and IDEs. This means you can use the full Codie agent—with all its capabilities including Skills, Hooks, and MCP integrations—in your preferred development environment.

## Why ACP?

- **Editor flexibility**: Use Codie in JetBrains, Neovim, Zed, or any ACP-compatible editor
- **No feature compromises**: Full access to Codie's capabilities regardless of editor
- **Team consistency**: Same AI assistant across different developer workflows
- **Open standard**: Built on Zed's open Agent Client Protocol specification

## JetBrains IDEs

[JetBrains](https://www.jetbrains.com) IDEs include IntelliJ IDEA, PyCharm, WebStorm, and more. They offer built-in AI Assistant with ACP support.

<Note>
**Recommended: Native JetBrains Plugin**

For the best JetBrains experience, install the [native Codie plugin](/getting-started/installing-codevibe#jetbrains-ides) from the JetBrains Marketplace. It provides full IDE integration and the complete Codie experience.

The ACP setup below is an alternative way to use Codie CLI features in JetBrains IDEs.
</Note>

Alternatively, you can run Codie CLI in IntelliJ IDEA, PyCharm, WebStorm, and all other JetBrains IDEs through their built-in AI Assistant with ACP support.

### Setup

1. **Install Codie CLI** (if not already installed):
   ```bash
   npm i -g codevibe
   ```

2. **Authenticate with Codie**:
   ```bash
   codevibe auth
   ```

3. **Configure JetBrains AI Assistant**:
   - Open your JetBrains IDE
   - Navigate to `Settings | Tools | AI Assistant | Agents`
   - Click "Add Custom Agent"
   - This opens/creates `~/.jetbrains/acp.json`

4. **Add Codie to `acp.json`**:
   ```json
   {
     "agent_servers": {
       "Codie": {
         "command": "codevibe",
         "args": ["--acp"],
         "env": {}
       }
     }
   }
   ```

5. **Use Codie**:
   - Open the AI Chat tool window
   - Select "Codie" from the agent dropdown
   - Start coding with Codie in your JetBrains IDE!

<Tip>
JetBrains AI Assistant can expose its built-in MCP server to Codie, giving Codie access to IDE-specific tools and context.
</Tip>

## Neovim

[Neovim](https://neovim.io) is a hyperextensible Vim-based text editor loved by developers for its speed and flexibility. Use Codie in Neovim through the [agentic.nvim](https://github.com/carlos-algms/agentic.nvim) or [avante.nvim](https://github.com/yetone/avante.nvim) plugins, which provide ACP integration.

### Setup with agentic.nvim

1. **Install Codie CLI** (if not already installed):
   ```bash
   npm i -g codevibe
   ```

2. **Authenticate with Codie**:
   ```bash
   codevibe auth
   ```

3. **Install agentic.nvim** using lazy.nvim:
   ```lua
   {
     "carlos-algms/agentic.nvim",
     opts = {
       provider = "codevibe-acp",
       acp_providers = {
         ["codevibe-acp"] = {
           command = "codevibe",
           args = {"--acp"},
         },
       },
     },
     keys = {
       {"<C-\\>", function() require("agentic").toggle() end, mode={"n","v","i"}, desc="Toggle Codie Chat"},
     },
   }
   ```

4. **Use Codie**:
   - Press `<C-\>` to toggle Codie chat
   - Start coding with Codie in Neovim!

### Setup with avante.nvim

Follow the [avante.nvim documentation](https://github.com/yetone/avante.nvim) for configuring external ACP agents and point it to `codevibe --acp`.

## Zed

[Zed](https://zed.dev) is a high-performance, multiplayer code editor built from the ground up for speed and collaboration. Zed's team created the Agent Client Protocol, making Codie a natural fit for this editor.

### Setup

1. **Install Codie CLI** (if not already installed):
   ```bash
   npm i -g codevibe
   ```

2. **Authenticate with Codie**:
   ```bash
   codevibe auth
   ```

3. **Configure Zed**:
   - Open Zed settings (`Cmd/Ctrl + ,`)
   - Add Codie to your `settings.json`:
   ```json
   {
     "agent_servers": {
       "Codie": {
         "type": "custom",
         "command": "codevibe",
         "args": ["--acp"],
         "env": {}
       }
     }
   }
   ```

4. **Use Codie**:
   - Open the AI assistant panel
   - Select "Codie" from the agent dropdown
   - Start coding with Codie in Zed!

## Other Editors

Any editor that supports the Agent Client Protocol can run Codie. Check your editor's documentation for ACP configuration instructions, then point it to:

```bash
codevibe --acp
```

## Troubleshooting

### Agent not appearing

- Ensure Codie CLI is installed globally: `npm i -g codevibe`
- Verify authentication: `codevibe auth`
- Check that `codevibe --acp` runs without errors
- Restart your editor after configuration changes

### Permission errors

If Codie can't access files or run commands:
- Check that your editor's ACP integration passes the correct working directory
- Verify file permissions in your project
- Ensure Codie has approval settings configured correctly

### Connection issues

- Make sure no other Codie instance is using the same configuration directory
- Check editor logs for ACP-related errors
- Try running `codevibe --acp` manually to test the connection
