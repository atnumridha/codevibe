Codie can connect to Google Gemini models through the Google AI API.

**Website:** [https://ai.google.dev/](https://ai.google.dev/)

### Get API Credentials

1.  **Sign Up/Sign In:** Go to [Google AI Studio](https://aistudio.google.com/). Sign in with your Google account.
2.  **Get API Key:** Navigate to [aistudio.google.com/apikey](https://aistudio.google.com/apikey).
3.  **Create a Key:** Click "Create API Key" and select or create a Google Cloud project.
4.  **Copy the Key:** Copy the API key immediately and store it securely.

### Configuration in Codie

> See [Authorization & Model Selection](/getting-started/authorization#menu).

1.  **Open Codie Settings:** Click the settings icon (⚙️) in the Codie panel.
2.  **Select Model Source:** Choose "Google Gemini" from the "Model Source" dropdown.
3.  **Enter API Key:** Paste your Google AI API key into the "Gemini API Key" field.
4.  **Select Model:** Choose your desired model from the "Model" dropdown.

### Tips and Notes

-   **Usage:** Refer to the [Google AI pricing page](https://ai.google.dev/gemini-api/docs/models/gemini) for current usage rates.
