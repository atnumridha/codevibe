# Security Policy

## Supported Versions

We actively patch only the most recent minor release of CodeVibe. Older versions receive fixes at our discretion.

## Reporting a Vulnerability

We appreciate your efforts to responsibly disclose your findings and will make every effort to acknowledge your contributions.

To report a security issue, please use [GitHub private vulnerability reporting](https://github.com/atnumridha/codevibe/security/advisories/new). We will acknowledge the report and coordinate fixes privately before disclosure.

When reporting, please include:

- A short summary of the issue
- Steps to reproduce or a proof of concept
- Any logs, stack traces, or screenshots that might help us understand the problem

Please keep the details private until a resolution has been reached.

## Escalation

If you are unable to submit through GitHub security advisories, open a minimal public issue that asks for a private security contact without disclosing exploit details.

Thank you for helping us keep CodeVibe users safe.
